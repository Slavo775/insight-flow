N168 deliberately preserved HANDOVER (out of scope), but the file now visibly diverges from its generator on that section; a `prompt-build --apply` in this repo would drop HANDOVER. Recommend reconciling separately (add HANDOVER to the generator, or drop it from the file and route handover discipline through `@AGENT_PROTOCOL.md`).
2. **Consumer upgrade needs two steps.** An existing consumer must run both `prompt-build --apply` (git-free enforcement + new AGENT_GIT.md) **and** `prompt-build --compose task-git --apply` (so the installed task-git role/command gains the `@AGENT_GIT.md` reference). Running only enforcement apply leaves AGENT_GIT.md written but unreferenced. Worth a line in the upgrade/release notes.
3. **Snapshot vs runtime redundancy (intentional).** task-git now carries both `permission-gates` ("read perms at runtime") and the `AGENT_GIT.md` static snapshot. Acceptable — the snapshot is explicitly labelled a quick-reference.
