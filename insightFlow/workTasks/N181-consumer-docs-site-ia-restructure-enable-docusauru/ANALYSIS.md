# N181 — Analysis (pre-taskmaster strategist)

## Problem framing

Discussion of overall docs strategy. The Docusaurus site (N178) is strong on
Reference but thin on the rest of Diátaxis, and has no versioning. This task is
the **foundation** of a multi-task documentation program — IA + versioning only,
no content prose.

## Diátaxis gap assessment (measured against the live site)

- Reference 🟢 — CLI (10), Agents (11), Flow (5), Configuration (N179), synced
  role files (15). ~90% of the site.
- Tutorial 🟡 — only `getting-started.md` (quickstart, not a guided lesson).
- How-to 🔴 — none.
- Explanation 🔴 — `overview.md` only; architecture diagrams exist in
  `docs/architecture-diagrams.md` but are not surfaced on the site.
- Visuals 🔴 — `website/static/img` empty (zero screenshots for a visual product).

## Options considered

- **Add more reference pages** — rejected. The gap is *balance*, not reference
  depth; more reference deepens the strongest quadrant while onboarding stays
  weak.
- **Audience-split IA (User Guide + Contributing)** — initially chosen, then
  **reversed** by the user: docs are **consumer-only**. This removed the
  riskiest piece (relocating the auto-synced `reference/` folder, which would
  have required editing `sync-docs.mjs`).
- **One umbrella epic vs sequence of tasks** — chose a sequence; **foundation
  first** (this task) so later content has a home and doesn't get reshuffled.

## Decisions (user-confirmed across the analysis turns)

1. Documentation is a **program** (≈5 tasks), not one ticket.
2. **Consumer-only** audience — no contributor/internals track.
3. Keep a **light user-facing Concepts** ("How it works") section.
4. Synced agent role/protocol files are **consumer reference** → stay in
   Reference; `sync-docs.mjs` untouched.
5. **Enable Docusaurus versioning now** (snapshot 2.0) — cheap insurance given the
   v1→2.0 break and future breaking releases.
6. **Foundation first**: IA + versioning (this task) before any prose/visuals.

## IA target

```
Get Started  → Overview · Quickstart · "Your first task" (stub)   [Tutorial]
Guides       → index + recipe stubs                               [How-to]
Concepts     → "How it works" index + stubs                       [Explanation]
Reference    → CLI · Configuration · Agents · Flow · Role files    [exists]
```

Achieved by **section grouping + `_category_.json` ordering**, deliberately NOT by
deep-nesting `cli`/`agents`/`flow` under a physical `reference/` parent (that
would collide with the synced folder). Only `overview.md` + `getting-started.md`
physically move.
