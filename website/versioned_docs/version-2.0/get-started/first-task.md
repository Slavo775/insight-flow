# Your first task

:::note Coming soon
A guided, end-to-end tutorial that walks a brand-new user through a single task
from creation to merge — the learning-oriented companion to the
[Getting Started](./getting-started.md) quickstart.
:::

This tutorial will take you, step by step, through one complete task lifecycle:

1. **Analyze & specify** — `/task-analyze` to pressure-test the idea, then `/taskmaster` to write `TASK.md` + `CHECKLIST.md`.
2. **Implement** — `/task-implement` against the spec.
3. **Review** — `/task-review` (AI) and `/task-human-review` (you).
4. **Ship** — `/task-git` to branch, push, open a PR, and merge.

Each step will show the exact commands, the expected output, and how the
dashboard reflects the task moving through its flow.

Until this lesson lands, the [Getting Started](./getting-started.md) guide is the
fastest path to a working setup, and the [CLI reference](../cli/index.md) +
[Agents](../agents/index.md) cover each command and slash command in depth.
